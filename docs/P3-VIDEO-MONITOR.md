## 使用

1. 设置 → YouTube API：沿用已配置的当前账号 Key。
2. 设置 → YouTube API → YouTube 字幕服务 · Apify：填写 Token，开启按需抓取并保存。连接测试仅查询 Apify 账号，不启动 Actor。
3. 合作项目 → 检测红人视频 → 开始新一轮检测。调用 YouTube、Apify 和用户配置的 AI 接口，可能产生各服务费用。
4. 查看候选的标题、公开时间、合作产品、AI 说明、文字命中和字幕时间点。分别确认、排除或保留待确认。
5. 确认仅保存看板内的“合作记录 ↔ 视频”关联，**不会自动写飞书**。在「待写回」选中视频 →「写回飞书」或全选后「批量写回飞书」→ 核对预览 → 确认写回，才更新原合作记录。成功项移到「已完成」；后续刷新统计使用「更新飞书数据」或「批量更新统计」，仍需确认预览。
6. 写回仅使用当前字段映射更新「实际上线日期、视频上线链接、曝光量（播放数）、评论量、点赞量」。默认一条合作对应一条视频；已有不同视频链接时阻止覆盖，多视频由用户手工处理。不额外写入另一个「红人合作视频」字段。

## 业务边界

- 每轮强制读取完整合作表，不受列表筛选影响；默认仅 YouTube 平台且“视频上线链接”原始单元格为空的合作。已有上线日期不阻止扫描。字段映射优先，复用既有读取别名；不更改飞书字段。
- 同频道去重读取，各合作记录、多个产品、多个视频分别保留；频道缺失/无法核实会单独报错，不按名称猜测。
- 从合作日期起比对；缺少合作日期时默认近 180 天。分页扫描上传列表，不只取最新视频、不排除 Shorts。每次每频道最多推进 8 页（400 条上传记录），仍有历史页时明确显示“待补查”，可继续检测。
- 标题/简介先匹配；品牌和准确产品型号同时命中时可直接进入候选。线索较弱或无命中时按需抓字幕。AI 只解释候选与预计日期，不自动确认合作。
- 暂归非合作仅用于取得完整字幕后仍无文字命中的情况；无字幕、抓取失败、超预算均保留待处理，不等同于“不是合作”。完整字幕不发送给 AI；只发送项目名/产品/预计原文及公开视频信息、命中摘录，不发送地址、费用、邮件正文。
- 预计时间保留原始文本；没有预计时间标记“新发布”。无明确年份的“9月上旬”等只展示 AI 解释，保守标为待核实，不擅自补年份判定提前。
- 确认/排除结果不因重复扫描被覆盖。已确认关联不等于飞书已更新，也不等于同合作的所有视频均已发布。

## 中断、存储与费用

- 大于 128 KB 的云端检测检查点在服务端使用 gzip 无损压缩，读取自动还原，兼容旧 JSON 记录；不删减简介、结果或进度，不修改表结构。解压限制为 16 MB，损坏内容拒绝读取而不是当作空结果。此次真实失败日志为 PGRST102 / incomplete-body（约 3.42 MB），压缩旨在降低大请求传输风险；实际恢复仍需验证。
- 检测进度和结果以当前账号、来源表隔离存储。云端保存使用更新时间比对，冲突不覆盖；未同步的本机快照保留，重新打开时只有云端版本未变才允许恢复。保存响应丢失时使用同一保存编号重试，若第一次已成功则认领原结果；真正的版本冲突、临时故障、数据过大分别提示。
- 分析每完成 50 条视频保存一次云端进度，中间逐条保留轻量本机记录，暂停/结束及提交字幕前后保存检查点。保存请求依次执行；重复的项目和视频快照在传输与云端存储中去重，读取兼容旧格式。保存失败后停止新增处理，重新读取并按提示恢复。
- 恢复本机结果每次先核对云端版本，再重建失败的保存队列；恢复失败后可直接再次点击，不必反复关闭弹窗。未同步增量不沿用已确认的保存编号，避免误认为已经同步。云端拒绝保存时仅显示安全错误码，不泄露正文或密钥。此恢复路径已通过隔离回归，用户真实云端失败原因仍待新请求核实。
- 2026-09-29 一键自动检测：最多 3 个频道并行，同频道顺序翻页；达到单次 8 页保护线后，在同一次点击中自动接续下一页。标题/简介强命中的视频优先分析。字幕每批最多 50 条，分析当前批时仅提前准备下一批；AI 最多并行 5 条候选。结果仍须人工确认，关键词标准未改变。
- 检测弹窗可关闭，当前网页仍打开时扫描继续；离开或刷新页面会暂停，已有进度可恢复。每次固定最多抓取 100 条字幕、调用 100 次 AI，达到上限停止新增调用；检测弹窗与设置页不再提供数字输入。字幕运行中最多自动等待 30 分钟；限流的 AI 最多延迟重试 2 次，频道读取的临时错误最多重试 2 次；未知状态的收费字幕提交不自动重复。默认只列待确认候选，其他状态可切换查看。
- 进度按已完成的视频 ID 保存，兼容旧版顺序进度；乱序完成后暂停/刷新不漏过前面较慢的视频。已处理且输入未变化的结果批量复用，不再次调用字幕和 AI；仍会用 YouTube 读取当前范围内的标题/简介以发现变化，并非完全不读取旧视频。
- 页面关闭/切换会暂停浏览器的检测流程，**不承诺网页关闭后整轮扫描继续**；已提交的 Apify 任务可在服务商端继续，保存 Run ID 后下次读取同一任务结果。
- Apify Actor 固定为 `scrape-creators/best-youtube-transcripts-scraper`，输入 `videoUrls`；使用异步启动、查询运行、读取 dataset 三步。Token 仅在服务端私密存储，通过 Authorization header 发送。
- 每个视频的字幕按账号缓存；提交前占位，提交响应丢失时不自动重提。可输入对应 Run ID 恢复，服务端会核对 INPUT 中的视频 URL。明确被拒绝的请求可修正设置后手动重试。
- 每次固定最多读取 100 个视频字幕、调用 100 次 AI。每次字幕运行请求设置 `maxItems=批次视频数（最多50）`、`maxTotalChargeUsd=0.05`、180 秒任务超时；一次检测可能包含多个 50 条批次，0.05 美元是单个批次的限制，不是整次检测的费用上限。预取也计入本次字幕上限，暂停不会撤销已提交的服务商任务；保存批次视频列表，继续时接续同一批次，不重新分组提交。实际全部费用仍以 Apify 账单及其计费规则为准。
- 首版不做定时巡检、自动飞书写回、P4 数据复盘；不保证发现未公开、已删除或不在时间范围内的视频。后续可单独扩展。
