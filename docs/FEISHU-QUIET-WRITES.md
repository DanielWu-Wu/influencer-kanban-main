# 飞书低风险写入减弹窗

2026-10-09 按当前工作区复核：建档/邀约及授权恢复入口为本地代码；不是上线或真实飞书验收证明。建档的现役操作和验收状态以 [PROSPECT-ONBOARDING.md](PROSPECT-ONBOARDING.md) 为准。

## 用户操作

- 主入口为“建档并进入邀约”。每次主动点击发起独立新轮次：已有资源档案复用，新建本轮开发记录并进入邀约；相同频道的多轮开发历史不作为资源档案重复处理。处理中锁定按钮，重试继续原轮次，不新开一轮。
- 红人录入中保留“加入资源库”“仅新建开发记录”次要操作，以及“继续本轮邀约”，用于已建成的旧记录和旧任务。可勾选“显示历史轮次”选择旧红人重新发起，旧邀约、邮件和草稿保留。
- “开发流程状态”保持选配：未映射时允许进入邀约，不提交空字段更新；邀约页隐藏本地阶段未同步的技术说明。有映射时只写阶段字段，同步结果与本地流程分别保存。
- 普通保存沿用原有保存动作。AI 推测、覆盖、删除和邮件相关确认没有统一关闭。
- 点击建档后，仅对新资源调用 AI 内容类型分类，从飞书可选项选择；手动类型优先。AI 失败或无可用选项时类型留空并继续，不增加人工选择步骤。已有关联资源不重新分类、不覆盖原类型。
- 录入页只有开发备注，不前置产品、合作形式和写信语言；主入口仅把备注带入该轮次。产品等在邀约页选择，逐条确认生成；批量确认入口与该页筛选框隐藏。合作想法最多三条自动并行准备，失败保留提示，用户主动重试；邮件审阅、保存草稿和发送仍由用户确认。
- 页面说明新建开发记录可能向准确关联的资源库追加已选邮箱，保留原邮箱。关联、邮箱或原值发生变化时暂停并要求处理。

## 防重复与恢复

- `prospect-feishu-write.ts` 保存不可变提交快照、原操作编号、分步骤状态和返回记录编号；在外部请求前同步保存本机日志，保存失败阻止请求。
- 准备阶段最多三行并行，按表和依赖步骤分批提交（每组最多 20 条），在提交前保存每条任务及不可变批次内容。明确失败后的单条重试使用该条原始单条标识和冻结字段，不重新提交其他记录；结果不确定的创建不能拆批或自动重试。同一资源记录有多条不同邮箱更新时，后续更新需核对最新原值，避免覆盖。
- 查重只投影必要字段，同批共享快照和索引；确认关联的资源按 ID 读取，阶段切换不扫描双表；写前查重每表每批复用一次刷新，已知记录更新仍核对最新原值。强制刷新复用进行中的请求，避免逐行整表重读。日志只保存该红人的历史候选 ID，避免每行复制整表编号。
- 开发记录成功而邮箱补写失败时，后者保留为待处理任务，仍可进入邀约和准备邮件。成功步骤不重复创建。
- 接口 `outcomeCertain` 是可选兼容字段。响应丢失、超时、缺少返回编号按“结果待核实”处理，不直接重复创建。
- 刷新不会自动恢复外部写入。未完成主任务可只读核对；未知创建要求用户提供准确新记录编号并验证原提交字段，不按名字相似程度关联。无法验证时继续暂停。
- 重试必须匹配原系统账号、双表地址及字段映射。旧页面延迟保存不能落入新账号。本轮不改变登录或权限规则。
- 飞书分页缺失或超过当前 10 页读取上限时，停止查重准备，不把不完整快照当成无重复。

## 授权恢复入口

- 当前会话状态接口调用 `getFeishuSessionState`：已读到应用凭证配置后，授权刷新失败仍返回该配置状态及 `reconnectRequired:true`，不会因刷新失败把 App ID/Secret 误显示为未保存。设置页显示“重新连接飞书”，链接仍为 `/api/auth/feishu`；配置状态接口整体失败时显示“重新检查连接”。
- 自动刷新是已有机制：令牌剩余有效期不足约 60 秒时使用刷新令牌请求更新。出现“飞书授权刷新失败 (400)”意味着刷新请求失败；本次只修复误报和恢复入口，没有证明或解决该次 400 的根因，也没有新增后台定期保活。
- `getFeishuSessionState` 目前将其刷新回调的所有异常归入需要重连；它没有进一步区分刷新令牌失效、网络错误或保存刷新结果失败。接口整体失败的“重新检查”分支不能被描述为所有暂时故障均已细分。
- `tests/feishu-session-state.test.ts` 覆盖刷新失败保留配置、已有有效授权、未授权时不刷新。2026-10-09 完整逻辑测试入口通过 415 项；重连 UI 夹具 `feishu-reconnect-ui.cjs` 存在，但没有成功报告，之前浏览器启动/本地页面访问失败，真实 OAuth 重连及三表读取验收仍待进行。
- `RecordIdNotFound` 是另一类记录定位错误；不能仅凭它判断授权掉线。用户截图中的 Gmail 草稿保存成功与飞书状态写回失败应分别处理，避免重复创建草稿。

## 限制

没有新增数据库表或依赖。沿用现有线索 JSON、本机缓存及已有云同步；本机日志不是服务端持久任务队列。不承诺关闭页面后继续执行、跨设备完全防重或云同步尚未完成时的跨设备恢复。

配置变更后旧任务需恢复原配置才能继续；无法确认结果时没有“强制重建”入口。本次知识收尾未构建、提交、推送、部署或真实写入；没有取得包含本次未提交功能的正式构建/部署凭证。

人工验收：红人开发台 → 识别并确定邮箱 → 建档并进入邀约 → 在邀约确认选择产品、合作形式和语言 → 核对方向 → 逐条确认生成开发信。再次发起新轮次可回红人录入、显示历史轮次并选择旧红人。点击建档会真实写入当前账号配置的飞书表，应由用户自行选择验收对象后操作；知识收尾不执行这项验收。
